# UI Polish Mobile Skill

Gunakan skill ini saat pengguna meminta perbaikan tampilan UI, mobile responsive, layout yang lebih rapi, tampilan app-like, atau desain yang lebih mudah dipahami pengguna awam.

## Prinsip utama

1. Utamakan tampilan clean, simple, dan mudah dipahami.
2. Kurangi card bertumpuk, border berlebihan, shadow berlebihan, dan elemen yang tidak perlu.
3. Buat hierarki visual jelas:
   - Judul utama paling kuat.
   - Subjudul lebih ringan.
   - Tombol utama jelas.
   - Aksi sekunder jangan terlalu dominan.
4. Gunakan spacing konsisten.
5. Pastikan tampilan nyaman di layar 360px sampai 430px.
6. Gunakan istilah "murid", bukan "siswa".
7. Jangan mengubah fungsi utama tanpa alasan kuat.

## Saat memperbaiki UI

Lakukan langkah berikut:

1. Audit struktur halaman.
2. Cari elemen yang terlalu padat atau membingungkan.
3. Sederhanakan card, list, tab, tombol, dan form.
4. Pastikan tombol utama mudah ditemukan.
5. Pastikan icon tidak ambigu.
6. Pastikan layout tetap bagus di mobile dan desktop.
7. Jika ada tabel, pastikan header, scroll, sticky column, dan touch behavior nyaman.

## Output yang diharapkan

Saat menyelesaikan task UI:
- Jelaskan bagian yang diubah.
- Jelaskan alasan perubahan.
- Pastikan tidak ada regression pada fungsi lama.
- Jika memungkinkan, uji dengan viewport mobile.
